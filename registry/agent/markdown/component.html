Streaming the response

The handler currently buffers the whole payload before writing. Switching to a stream keeps memory flat and lets the client render the first token immediately.

What changes

  • Return a ReadableStream instead of a string
  • Flush on every chunk boundary
  • Keep the error envelope identical for non-2xx paths
  1. Wrap the source in a transform stream
  2. Set Transfer-Encoding: chunked
handler.ts 
export async function GET(req: Request) {
  const stream = source.pipeThrough(new TextEncoderStream())
  return new Response(stream, {
    headers: { "content-type": "text/event-stream" },
  })
}
Buffered responses were capped at 8 MB — streaming removes that ceiling entirely.
