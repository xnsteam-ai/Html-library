Configuration

Halyard reads a single halyard.config.ts at the root of your repository. Every field is optional — the defaults cover most projects.

Minimal example

halyard.config.ts Copy 
export default {
  build: { command: "npm run build", output: "dist" },
  previews: { perBranch: true },
}

Config changes take effect on the next deploy — running builds keep the settings they started with.

Options

Field Type Default
build.command string "npm run build"
build.output string "dist"
previews.perBranch boolean true
