Button

March 30, 2026 · Updated 5:40 p.m. PST

Usage

Buttons provide visual cues for actions and events. Use a Button when a user needs to submit a form, start a new task, or trigger a new UI element to appear on the page.

Best practices

Do Each surface should only have one primary button.
Don't Overuse colored buttons — it creates visual confusion.
